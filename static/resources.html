How to run the loop.

Setup that actually sends. Listings that actually scan. Reviews that only exist when a customer writes them.

Google Place ID

Paste your Place ID in Settings so 4–5★ reviews open the real Google write-review URL — not a placeholder.

SMTP / Twilio

Set SMTP_* or TWILIO_* so review requests actually leave the building. Until then, the live /r/ link still works from the dashboard.

Free review analyzer

Paste any set of reviews and see the themes — staff, wait time, price, cleanliness — plus what to fix first. Open the analyzer →

Review math

Ask every walk-out. Private the lows. Public the highs. That’s how rating and revenue move together.

Listings scan

OpenStreetMap looks up your NAP. Missing listings report as not found. Nothing is marked “synced” unless it is.

Ask AI

Dominate unlocks Ask AI on your reviews. Grok reads the real corpus — empty shops get an honest empty answer.
